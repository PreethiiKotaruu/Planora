# Planora

> Turn confusing group chats into one clear plan.

Planora is a full-stack group-planning platform where friends can create private groups, suggest activities, vote on options, discuss plans, and finalize decisions together.

## Project Status

🚧 Currently under development.

## Planned Technology Stack

### Backend

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL

### Frontend

- React
- TypeScript
- Tailwind CSS

### Testing

- JUnit
- Mockito
- REST Assured
- Testcontainers

### DevOps and Cloud

- Git
- GitHub
- Docker
- GitHub Actions
- AWS

### AI Enhancement

- Spring AI
- OpenAI API or Claude API

## Development Approach

Planora is being developed through an eight-week company-style software development process:

1. Requirements analysis
2. Product and technical design
3. Feature-based development
4. Automated testing
5. Pull request reviews
6. CI/CD
7. Cloud deployment
8. Real-user feedback
